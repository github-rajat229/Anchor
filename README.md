# Responsive Navigation Overlay Pages

A collection of lightweight, full-screen landing pages featuring modern CSS linear gradients, centered pill-style navigation bars, and fully responsive layouts.

## Features

* **Responsive Viewport Design:** Built using `vh`, `vw`, and CSS `clamp()` functions to ensure seamless rendering across mobile, tablet, and desktop viewports.
* **Centered Navigation Bar:** Pill-shaped floating navbar vertically and horizontally centered over full-screen hero backgrounds.
* **Interactive Hover Effects:** Smooth scaling transitions on link elements.
* **Multiple Color Schemes:** Includes variations across different gradient color themes (Red/Black, Cyan/Black, Purple/Black, Magenta/Black, Green/Black).
* **Zero Dependencies:** Built entirely with pure HTML5 and CSS3.

## Color Variants

* `home.html` — Red to Black (`linear-gradient(40deg, red, black)`)
* `aboutus.html` — Cyan to Black (`linear-gradient(40deg, cyan, black)`)
* `gallery.html` — Purple to Black (`linear-gradient(40deg, purple, black)`)
* `achievement.html` — Magenta/Pink to Black (`linear-gradient(rgb(255, 57, 242), rgb(0, 0, 0))`)
* `contactus.html` — Translucent Green to Black (`linear-gradient(40deg, rgba(0, 128, 0, 0.639), black)`)
